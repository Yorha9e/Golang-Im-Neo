Architecture

五层解耦 · 单向依赖

严格遵循依赖倒置原则：下层绝不反向依赖上层，上层通过 Go 接口与下层交互。 业务领域层零网络框架依赖，可被 HTTP 与 WebSocket 双通道复用。

1
握手与协议升级层 internal/handshake/
一次性 Ticket 核销（30s 有效、用后即废），在 HTTP 层直接拒绝非法升级请求， 杜绝未授权连接消耗 Socket 句柄。校验通过后组装握手上下文并移交网关层。
▼
2
网关接入层 internal/gateway/
32 分片连接池各自持有独立锁，按用户哈希定位分片，消除全局锁竞争。 读写泵分离，慢客户端由非阻塞背压熔断主动剔除；广播路径单次序列化后共享字节切片。
▼
3
路由与策略调度层 internal/router/
四道拦截器按洋葱模型串联：令牌桶限流 → 身份保真覆写 → 好友关系校验 → 群成员校验。 经策略接口分流至中心化代理或 P2P 信令旁路，两类路径共享同一套幂等与发号基础设施。
▼
4
业务领域服务层 internal/logic/
九个独立子域：认证、用户、好友、群组、媒体、消息、资料、会话、管理。 入参出参均为纯 Go 结构体，不依赖任何 Web 框架，具备高可测试性与可迁移性。
▼
5
异步持久化存储层 internal/store/
Repository 接口抽象屏蔽 SQL 细节，单写句柄串行化写入规避并发锁冲突， 读句柄并发支撑查询；WAL 模式配合主动检查点治理磁盘体积。
Send Pipeline

一条消息的完整旅程

从客户端生成幂等键，到对端收到推送，全流程包含四道安全拦截、三重幂等校验与一次批量事务落盘。

STEP 01

客户端提交

生成 stanza_id 幂等键并乐观上屏，二进制 Protobuf 帧发出。身份字段一律留空，由服务端权威赋值。

STEP 02

四道拦截

限流熔断泛洪、强制覆写发送者身份防冒名、校验好友关系、校验群成员与禁言状态。任一不通过即中断。

STEP 03

幂等与发号

先查内存去重窗口，命中则直接重放历史 ACK；未命中则向水线发号器申请会话内单调递增序号。

STEP 04

批量落盘

消息进入内存队列，后台 Worker 聚合成批执行事务。仅当事务确认提交成功后，才向发送者回执 ACK。

STEP 05

回执与扇出

发送者收到含权威序号与时间戳的 ACK；接收方按路由策略收到单点投递、全服广播或群成员扇出。

STEP 06

失败可收敛

落盘超时返回错误提示，但消息可能稍后成功入库。客户端携原幂等键重试即命中去重层，状态最终收敛为成功。

// 会话级独立序列空间：两端按字典序排列，保证双方命中同一会话
func buildCovID(uid1, uid2 string) string {
    if uid1 < uid2 {
        return fmt.Sprintf("cov:%s:%s", uid1, uid2)
    }
    return fmt.Sprintf("cov:%s:%s", uid2, uid1)
}

// 去重命中即重放历史 ACK —— 不落盘、不推送、不二次发号
if stanza != "" {
    if seq, ts, ok := s.dedup.Lookup(covID, stanza); ok {
        s.sendAck(ctx, stanza, seq, ts)
        return nil
    }
}

DEFENSE

边缘防护

长连接容量

Deployment

容器化一键部署

后端沙箱与边缘网关组成双容器拓扑，应用端口完全处于私有网络，公网无法直接探测。

01 · 打包

本地构建产物

编译前端静态资源，打包核心文件并排除依赖目录与临时库文件，通过 SCP 上传至服务器。

02 · 启动

容器编排拉起

单条 compose 命令完成镜像构建、私有网络创建与服务启动，后端健康检查通过后网关才开始转发。

03 · 验证

探针与访问

通过健康检查探针确认服务状态，浏览器直接访问统一入口即可进入全功能工作台。

04 · 运维护航

数据与备份

数据库与媒体文件挂载在宿主机目录，归档即备份。优雅停止会预留时间排空落盘队列。

# 一键拉起双容器集群（后端沙箱 + 边缘网关）
docker compose up -d --build

# 检查容器健康状态
docker compose ps

# 健康检查探针
curl http://127.0.0.1:8080/health

# 数据备份：数据库与媒体文件均挂载在宿主机目录
tar -czvf im_backup_$(date +%Y%m%d).tar.gz ./data ./config.toml
